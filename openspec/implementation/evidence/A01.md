## 已知语义裁定（记录给后续包）

1. `DexText::as_str` 返回 `Option<String>`（owned）：units 是唯一存储，避免大语料双份内存；接口文字"as_str 只在合法 Unicode 时给文本"的语义保持，仅所有权形式为 owned。DTO 消费无影响。
2. prototype 的 DTO 是结构对象 `{parameters:[DexText], return_type:DexText}`（无损），text 渲染 `(…)ret` 形式由 A08 投影。
3. 模糊类 regex 直接作用于 descriptor 文本（含 `/`），不转换点号——literal 模糊类才做 `.`→`/`。与 design"regex 原样作用于 descriptor"一致。
4. exact_descriptor 对 `I`/`V` 等 primitive 拼写产出 `LI;`/`LV;`（默认包同名类，合法 class descriptor）；数组 `[L…;` 与 body 含 `;`/`[` 的拼接形式拒绝。
5. Pattern 运行期 backtrack 超限返回 ResourceLimit（fancy-regex is_match 的 Err 映射），A03 扫描器必须传播而非吞掉。
