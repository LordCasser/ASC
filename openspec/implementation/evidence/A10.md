状态：已实施（workspace 拆分 + Engine/Artifact 公开 API + feature 门），集成 owner 本人执行。base `2388855`（A09）。

## 布局（extract-publishable-core design §1）

```
Cargo.toml (workspace: asc-core, asc-cli, vendor/droidsaw-dex, vendor/axmldecoder;
            default-members = 两个产品包; root [patch.crates-io] 删除, vendor 走 path 依赖)
crates/asc-core/   package asc-core, lib asc_core
  src/engine.rs    Artifact/Root/open*/dexes/classes/references + Engine 包装
  src/engine.rs    #[cfg(feature="decompile")] decompile + BackendMetadata 映射
  src/engine.rs    #[cfg(feature="manifest")] manifest 操作
  src/{model,error,query,bytes,zip}.rs, src/dex/*（A01–A03 冻结模块, pub 面收敛）
  src/manifest.rs  (feature manifest: A06 领域模型; OperationControl 移至 bytes.rs 未门控)
crates/asc-cli/    package rasc (bin), 依赖 asc-core path + features decompile,manifest
  src/{main,cli,render,output}.rs
tests/fixtures/contracts/  保留在仓库根（vendor asc_contracts 的 include_bytes 相对路径不变）
```

- **公开 API**（interfaces §2）：`Engine::new(EngineOptions)/open_path/open_bytes/dexes/
  classes/references/decompile/manifest`；`InputKind::{Apk,Dex}`；raw DEX 入口
  （entry ordinal 0、显示名 `<memory.dex>`、manifest → NotFound）；`Artifact::id()`。
- **features**：default = 输入/classes/references（zip/dex/bytes/model/query/error 无第三方
  反编译/XML 依赖）；`decompile`/`manifest` 各自拉起可选依赖。查询语义不随 feature 变化。
- **OperationControl** 从 manifest.rs 移到 bytes.rs（未门控），manifest 重导出。
- ** Limits/ScanLimits 字段转 pub**：宿主显式调高的入口（interfaces §5）。
