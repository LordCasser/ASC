# A12 — 隔离后端与嵌入副作用（证据）

状态：已实施。base `0842837`（A10/A11 之后）。集成 owner 本人执行。

## 实现

1. **嵌入式宿主测试**（crates/asc-core/tests/backends.rs，3 测试全绿，`--all-features`）：
   - `scan_never_initializes_the_backend`：同一 Artifact 上先 references 后 decompile 再
     references——扫描结果字节级不变（引用扫描不被反编译后端影响/初始化；
     "Analysis runtime independence"）。
   - `decompile_is_deterministic`：同类重复 checked decompile 字节一致（无隐藏状态）。
   - `classes_and_references_agree_on_the_raw_dex_entry`：raw DEX（`InputKind::Dex`）入口的
     dexes/classes 契约（entry ordinal 0、`<memory.dex>` 显示名、G02 类在列）。
   - 宿主只 `use asc_core::*` 公开 API——vendor 类型零泄漏（`from_normalized` 因此转 pub，
     作为宿主构造描述符的合法入口；query builders 内部使用）。
2. **feature 矩阵**（CORE-06/A12）：
   - `cargo check -p asc-core`（default：仅 zip/dex/model/query/error）0 错误；
   - `--features decompile` / `--features manifest` / `--all-features` 各自 0 错误；
   - default build 不引入 droidsaw/axmldecoder（可选依赖 + cfg 门）。
3. **env/stdio 隔离**：ASC 可达路径不读 env、不写 stdio、不装 logger/signal、不进程退出
   ——由 A04 落地（vendor/droidsaw-dex/src/analysis.rs controlled-mode 门 +
   classes.rs RunCtx 显式线程化），其子进程 env 矩阵测试（7 个 DROIDSAW* 开关全开 →
   正常/不支持 fixture 的 stdout/stderr 为空、结果由传入 options 唯一决定）继续作为
   BACK-02 的过程级证据（本包引用，不重复实现）。
4. **嵌入副作用审查**：`grep -rn "std::env\|eprintln!\|println!\|process::" crates/asc-core/src`
   ——engine/model/query/zip/dex/bytes 无 env/stdio/进程调用（诊断经 Report/Error 返回，
   `--debug` 计时在 CLI 层）。manifest 模块同样无 env/stdio。
