contract_harness 的 8 个测试项：

1. `manifest_has_unique_well_formed_cases`：schema、case_id 唯一且 kebab-case、owner_package ∈ A00–A14、status/outcome/facts_kind/source.origin 合法、input 路径与 sha256/size 形状、planned 不带 input、process 不带 input。

3. `active_inputs_exist_with_matching_sha256_and_size`：文件存在、size、sha256（自带实现）逐 case 匹配。
4. `generated_inputs_match_the_registered_generators`：Rust make_dex/make_static_field_dex 的 sha256 与 Python 常量相等（常量注释记录生成命令）；g01/g02/g03 的 5 个 input 与构建器输出逐字节相等；清零只触碰 8..32。
5. `pass_case_facts_parse_and_carry_at_least_one_fact`：active+pass 的 facts 全部可解析且非空；process 类必须有非空 procedure/pass_criteria。
6. `comparator_flags_removed_references_and_edited_source_text`：负向自测——删除 tok.n 查询的一条真实引用、篡改 SECOND=22 断言都必须报差异；顶层 multiset（乱序相等、缺项不等）、manifest 有序语义、整数/浮点不相等；正向对照（自身比较零差异）。
7. `sha256_verification_fails_on_a_flipped_input_byte`：翻转一字节后 sha256 必须不再匹配。
8. `regenerate_fixture_inputs_when_explicitly_requested`：显式 opt-in 的再生成入口（默认直接 return，不属于跳过断言）。

## 设计决定与已知限制

1. **regex 查询语义**：facts 按"regex = 非锚定 search（fancy-regex is_match）"编码。任务卡曾写 `tok(en|x)` 只命中 "token"，但该语义下 "tokens" 含 "token" 子串同样命中；无论 search 还是 full-match 两种标准语义都无法同时满足任务卡的两条命中描述。facts 同时登记了 `tok.n`（两处命中）、`tok(en|x)`（两处命中）与 `^token$`（仅一处）三个查询，单命中预期由锚点查询承担。A03 实现 fancy-regex 语义后此文件即为合同。
2. **诊断码为提案**：g03 facts 中的 DexChecksumMismatch/DexSignatureMismatch 是 A00-a 提名，A02/A07 冻结 Diagnostic 码表时若改名需同步更新 manifest 与 facts（manifest notes 已声明）。
3. **planned case 的 facts_path 为 null**：登记 case_id/facts_kind/outcome/owner，不预写 facts 文件；"pass 用例 facts 非空"断言只约束 active（planned 转 active 时由 harness 强制补齐）。
4. **process case 的 input 为 null、status=active**：这是任务卡第 4 条对 schema 规则的显式例外，harness 按例外实现并校验（active 且非 process 才必须有 input）。
5. **owner_package 取"实施→验收"列中验收前最后一个实施包**（如 BACK-02→A12、QUAL-03→A14），便于交接；如集成 owner 另有分工可只改 manifest 单字段。
6. **QUAL-02 指向 corpus/**：`tests/fixtures/contracts/corpus/` 由并行的 A00 corpus 子任务拥有（本轮已存在其 registry.json 等），本任务未写入该目录；qual02 process case 的 procedure 指向该注册表。
7. **APK 生成器当前仅 stored entry**：deflate/descriptor 变体留给 A02 的 in02 用例（generators.md 已注明扩展点）；不引 zlib 依赖避免跨机器字节漂移。
8. **`cargo +1.93.1` 前缀**：默认 stable=1.88 低于 MSRV，属本机环境问题而非仓库问题；CI/其他机器若默认 ≥1.93 可去掉前缀。
9. bench/*.py、tests/fixtures/contracts/corpus/ 为并行 agent 的修改（git status 可见），本任务未触碰；src/、vendor/、Cargo.toml/lock、Python 基线均未改动。
