1. 实现 ZIP 支持矩阵、CD/local/descriptor/CRC/流完整性、重复 entry 原 ordinal 数据；只处理格式发现，不在 low-level 做 getclass 首命中选择。
2. 实现 035/037/038/039/040/041 明确版本与 checked view；保留整个 041 容器地址空间、逻辑 header offset 和稳定 ordinal。
3. 区分 checksum/signature warning 与结构失败，定义只读 scratch normalization 和原偏移映射；不得改用户 bytes。
4. 提供有界 input/view/解压入口及 control 检查点；A11 后接 Engine permits，当前增长/计数上限必须真实执行。交接 prefix/full 校验义务。
