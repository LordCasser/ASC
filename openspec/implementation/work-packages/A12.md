# A12 — 隔离后端和嵌入副作用

状态：待实施。可分配给一个 agent；前置包通过并合入后才开始，不通过的前置不是“边做边等”的接口。

## 输入与写入范围

前置：A10。

先读：[统一接口](../interfaces.md)、[验收矩阵](../acceptance.md)、[执行规则](../../execution-plan.md)，以及 A04/A05/A06 后端合同，A10 OperationContext；所有可达 env/stdio/typed values/041 scratch 与 public feature。

允许写入：crates/asc-core/src/decompile/**、manifest/**、tests/backends.rs、examples/decompile.rs、examples/manifest.rs；必要 CLI 调用调整限定 crates/asc-cli，独占约定后执行。

## 实施闭环

1. 只调用派生 checked entry，转换全部 method/metadata outcome、错误和 budgets/control，不让 vendor 类型或非 Send Rc 越过 API。
2. 消除核心与可达第三方 env/stdio/logger/signal/cwd/process 副作用；宿主显式 options 唯一决定结果。
3. decompile/manifest feature 各自独立，开启任意组合不改变 references；Manifest XML 属于 core 显式领域操作，CLI 只选格式/目的地。
4. 把 G02/G03/041/AXML 全行为重新跑在只依赖 core 的宿主里，接入 A10 context；真实资源行为最终联合 A11 测试。

## 验收与交接

BACK-02、CORE-05/06、DECL/MAN 行为快照、default 与各 feature 的相同引用结果；cargo test -p asc-core --all-features --test backends。

交付：可达依赖检查/副作用子进程测试、功能组合报告、后端资源映射，A11/A12 联合测试无冲突。 证据写到 `openspec/implementation/evidence/A12.md`，按验收文档记录实际命令/环境/结果和失败项；提交给集成 owner 复核后才标记完成。

## 范围限制

不改 Engine/resource/model 接口、不自己建 pool，不把大量 vendor src 内嵌到 core，不保留双后端。
