# A11 — 实现资源生命周期和取消

状态：待实施。可分配给一个 agent；前置包通过并合入后才开始，不通过的前置不是“边做边等”的接口。

## 输入与写入范围

前置：A10。

先读：[统一接口](../interfaces.md)、[验收矩阵](../acceptance.md)、[执行规则](../../execution-plan.md)，以及 interfaces 第 2–5 节及 A10 OperationContext，线程池、Arc/account/drop、041 与解压增长路径。

允许写入：crates/asc-core/src/engine.rs、input/**、runtime/**（如需要）、tests/runtime.rs、examples/resource_limits.rs；共享 model/query/error/lib 和 backend 模块不写。

## 实施闭环

1. 实现每 Engine 一池、Clone 共账户、顶层串行可取消准入、内部并行；input 保留不足立即报错，避免互相持额度等待死锁。
2. 全部有限 Limits 与 checked accounting/RAII；共享 041 view 一份物理 bytes，scratch 按操作计量；返回结果脱离 Engine permits，宿主历史结果范围明确。
3. 实现读取/解压/扫描/context 检查点、deadline cause、准入等待取消、错误释放和复用；返回前 join 已派发工作，测试不残留后台任务。
4. 首版无跨操作索引/源码缓存；固化初始 defaults 的边界测试与 RSS 报告，后端不可控分配单列；必要改值更新 spec，不能声称 RSS 硬限制。
