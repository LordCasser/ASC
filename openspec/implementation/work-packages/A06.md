# A06 — 修复 AXML 与 manifest 领域转换

状态：待实施。可分配给一个 agent；前置包通过并合入后才开始，不通过的前置不是“边做边等”的接口。

## 输入与写入范围

前置：A01。

先读：[统一接口](../interfaces.md)、[验收矩阵](../acceptance.md)、[执行规则](../../execution-plan.md)，以及 现有 PATCHES 1–8、binaryxml/stringpool/xml 数据流、validate_chunks/render_node、interfaces 的文档模型和纯 XML 策略。

## 实施闭环

1. 保留来源与 1–8 修复，补 raw type/data/string metadata，不以 formatted value 为唯一事实。
2. 修 namespace scope/start-end 匹配/单根后完整消费/扩展长度/style spans/CDATA/text-tail；非法结构与资源超限明确错误。
3. 纯 XML 采用已发布 pull reader（首选 [quick-xml](https://docs.rs/quick-xml/latest/quick_xml/)），显式 UTF-8、单根/匹配/namespace 校验，不启用外部 DTD/entity 解析；不要 trim mixed content。
4. 新的文档入口返回自有 Manifest 并提供 XML 序列化；vendor Rc 不越出 adapter；typed 精度/未知值/raw bits 在 JSON 模型可保留。可暂保留旧 decode 的字符串桥接使当前 CLI 编译，由 A07 删除；不得长期保留双实现。

## 验收与交接

交付：AX-P01–04 账本、Manifest/XmlRenderOptions 的固定接口、纯 XML feature/dependency 请求、archive 需包含的 fixture 和 target。 证据写到 `openspec/implementation/evidence/A06.md`，按验收文档记录实际命令/环境/结果和失败项；提交给集成 owner 复核后才标记完成。
